# California-labor-market-dashboard
A Power BI dashboard analyzing California labor trends (1990-2024) using statistical modeling and AI diagnostics.
## 📊 Project Overview
This project explores the structural shifts in California's labor market over a 34-year period (1990–2024). The core objective of this analysis is to move beyond simple employment counts to identify and diagnose the underlying patterns of economic volatility. By examining this extensive historical timeline, the project provides a comprehensive view of how systemic economic cycles have reshaped the state's workforce, offering a clear narrative on long-term labor trends and structural market changes.

## 🛠️ Methodology
The analysis and visualizations were engineered entirely within **Microsoft Power BI**. To effectively track and interpret market fluctuations, the project steps beyond standard descriptive reporting by utilizing advanced analytical techniques:
* Statistical Modeling: Applied standard deviation and variance analysis to mathematically measure and track economic volatility across different sectors and timeframes.
* Targeted Visualizations: Developed custom scatter plots, ribbon charts, and funnel charts, deliberately chosen to highlight statistical anomalies, trend divergences, and market distribution.
* AI-Driven Diagnostics: Integrated Power BI's Key Influencer visuals to run automated diagnostics, isolating the specific variables and conditions that most significantly impact labor market shifts.
